# 向量空间 3D 可视化 Demo

一个零外部网络依赖的单页 Web Demo：用一个 JS 数组表示向量空间中的若干向量，在 3D 场景中从原点渲染为带箭头的向量，并提供自动旋转动画、可编辑数组重绘、向量加法演示，以及并排的多组样本范例。

## 功能
- **3D 渲染**：基于 Three.js（本地 vendored，无 CDN），x(红)/y(绿)/z(蓝) 三轴 + 网格；向量数据模型支持 `[x, y]` 或 `[x, y, z]`（二维自动兼容为 z=0）。
- **动画**：`requestAnimationFrame` 驱动场景自动旋转；支持鼠标拖拽调整视角。
- **可编辑**：文本域输入 JSON 向量数组，点击「绘制 / 更新」重绘；非法输入有友好校验提示并保留上一次合法画面。
- **向量列表**：显示每个向量的坐标与模长。
- **向量加法**：勾选可显示 a+b 结果向量与辅助线。
- **样本范例**：并排 4 组独立 3D 小图——标准正交基 i/j/k、线性相关组、3D 立方体顶点方向、一般向量组。

## 运行
ES 模块需经 HTTP 加载（不能直接 `file://` 双击）：

    python3 -m http.server --bind 127.0.0.1 8080

然后浏览器打开 http://127.0.0.1:8080/index.html

## 文件
- `index.html` — 页面与全部应用逻辑
- `vendor/three.module.min.js` — Three.js r168 ESM 构建（本地打包，保证离线可用）

## 依赖与离线
除页面自身与 `./vendor/three.module.min.js` 外，不发起任何外部网络请求。
